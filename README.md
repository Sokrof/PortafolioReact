# Portafolio de Daniel

Soy Daniel y este portafolio es un proyecto personal en continuo desarrollo. Lo he creado para reunir mi experiencia académica, laboral y personal en un mismo lugar: qué he aprendido, en qué he trabajado y qué proyectos me ayudan a seguir creciendo como desarrollador.

Lo estoy construyendo con React y Vite. Elegí una estética inspirada en los videojuegos porque me permite dar al recorrido una identidad propia y reflejar también mi interés por crear experiencias digitales cuidadas.

## Qué encontrarás aquí

Actualmente puedes consultar mi experiencia laboral y mi formación. Estoy preparando las secciones de proyectos, presentación personal y contacto para explicar mejor el trabajo que he realizado y las áreas en las que quiero seguir desarrollándome.

Me gustaría que este espacio ayude a empresas y equipos a conocer mi trayectoria y mi forma de trabajar. Seguiré revisando el contenido y la interfaz a medida que avance el proyecto.

## Ejecutar el proyecto

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```
